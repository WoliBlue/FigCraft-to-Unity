# Changelog

## [0.1.0-preview.1] - Unreleased

- Capture uGUI screens in Play Mode into FigCraft (layers, baked images, TextMeshPro text, anchors as constraints).
- Design Changes window: apply position/size, text, font size, alignment, colour and image edits back to the game.
- Capture Selection Only: one panel and its children, without the 3D world.
- Elements inside World Space canvases can be moved and resized from FigCraft.
- UI built by a script at runtime: the window names the scripts that probably build it.
- Runs entirely inside Unity: install from a git URL, no separate executable or .NET SDK.
- MIT licence.
